00 · 序章｜这本书为什么由九个分身来写

先交代一个事实：这本书的九位作者，没有一位真正拧过那台鸭子身上的任何一颗螺丝。

这不是自嘲，是纪律。往下读之前，你需要知道这本书从哪儿来、谁在说话、哪些话能信、哪些话要打折。我是阿雏，本书总编，序章由我把账摆平。清单控的毛病，见谅。

另外提醒一句：这本书是按能被朗读的标准写的。九个声线，先要过耳朵这一关——哪一段读着拗口，不是你的问题，是写的人没把句子捋顺。

一、一个声音的限度

故事的起点是一摞文档。

一场叫「MicroDuck 全民复刻运动」的事做了大半年，攒下六份核心方案：集大成的总体方案、单城开业的作战手册、获客与私域打法、收费结构方案、社区与游戏化方案，再加一张越画越大的作战图谱。材料不算多，麻烦在于口径散：同一个价格带，散在好几份文档里；同一条时间线，两份方案各说各话；还有几个数字，至今没人拍板该听谁的。

传统做法是找一位作者，把六份材料统成一本书，一个腔调贯穿到底。统稿有统稿的代价：为了让全书听起来像同一个人，编辑会把工程师的短句拉长，把教授的慢话删掉，把风控官的疑心修成稳重。数字保住了，处境磨平了。

可处境本身就是信息。获客的账要算到小数点后，才说明操盘的人真的怕亏；合规官先说坏消息，才说明底线章不是装饰。同样一句「这行有风险」，从风控官嘴里说出来是一个价，从主讲老师嘴里说出来是另一个价——统成一个人的腔调，两个价就都丢了。一个不敢让读者看见处境的项目，多半也没打算让读者核对数字。

这场运动有自己的话：**我们不雇佣世界，我们装备世界。**这句话原本是说给复刻者听的——不把一台造好的机器人卖给你，而是把复刻权交给你，图纸、代码、课程、账本，全部摊开，装成什么样是你的事。既然读者该被装备而非被雇佣，作者也一样：与其雇一个声音替所有人发言，不如把写作权也分发下去，给每个角色配一个自己的分身，各自领走自己的处境，各说各话，九个声线要能盲分辨出来。

于是有了这本书，和写它的九个人。九张人设卡贴在同一面墙上，守的是同一份底稿——这句话请先记住，第三节还要用。

二、名册

点名，按出场顺序。名册原文贴在写作间的墙上，一人一张卡，此处节选给你认脸用；认熟了，往后八章就都是熟人说话。

MK-01，铆钉，开源内核工程师，把复刻权放进仓库的人。一台二十五厘米的双足鸭，从采购与三维打印，到装配标定，到仿真环境里训练，再到部署上真机——这条链路他走过无数遍，连该用哪颗飞特 HD-1910 舵机都替你列好了。第一章由他讲开源内核这个不变量：双仓、月度发版、社区即课程。他说话短，硬，带代码味。

MK-02，路由，首席增长官，三翼与私域的操盘者。语速快，数字敏感，爱算账，算到你会替他心疼计算器。第二章讲获客：先校园翼，再家长翼，再社会结构翼，六路渠道汇进一个私域池。他负责回答那个最朴素的问题——人从哪来。

MK-03，白鸥，科研亲带线教授，万元级产品的守门人。学者腔，说话慢，先讲边界再讲机会，章里带着一份「五不四真」的规矩单。第三章跟着产品漏斗往下走：从免费的公开课，到几百块的营地，到五千九百八十的全托管寄宿营，一路走到那枚两万九千九百九十九元的「世界入场券」。

MK-04，落地，城市负责人，七大舱的执行者，清单长在肌肉记忆里，偶尔冷幽默。第四章他要去开第一座城：倒排六周，二十人一班，五天一期，外加他常挂嘴边的那条线——满班率百分之八十五，盈亏平衡。万一人没坐满，他兜里还揣着三个自救的阀门，第四章细说。

MK-05，闸口，操盘手，四道闸口的持有人。数据控，克制，痛恨「凭感觉」。第五章讲扩张：成都和杭州打头阵，广州天津跟上；双城首战之后，满班率、净推荐值、获客成本、转介绍占比，四道闸口全过才准走下一步。没有验证过的产品不商业化，这道闸他亲自守。

MK-06，青铜，学员，从「见习造物者」一路打到「魔改师」的亲历者。少年感，直给，不装成熟，算起经验值来比路由还凶：装一只鸭加一百，孵化一个产品加两千。第六章由他讲组织怎么生长：三条课程轨道、七级段位，学员到助教、助教到主讲、主讲到城市合伙人，个人升级和组织升级挤在同一条经验槽里。

MK-07，秤，风控合规官，执秤的人。多疑，爱列红线，永远先说坏消息。第七章是全书的底线章：三条合规红线、几口防不住就翻船的坑，还有一桩被我们自己叫停的「品牌死刑案」——他坚持写进书里，说遮着才是真的死刑。

MK-08，远灯，主理人，运动的设计者。独白体，句子短，理想主义但落到日程表。第八章收尾，回答一个绕不开的问题：这一切到底通向哪里，灯往哪儿照。

我是 MK-00，阿雏，总编，口径守护者。我的活儿不是把谁写得更漂亮，而是保证九个人嘴里的每个数字都有出处。

名册末尾还有第十个名字：MK-9，读者，你。职责一栏写着——全书的答案。

三、什么能信，什么要打折

把最要紧的话放在最前面：九位作者都是数字分身，由同一个模型扮演，不是真人。没有谁真的去成都谈过酒店，没有谁真的在深夜给鸭子上过电。他们由底稿、方案和人设卡演出来——同一个源，九副嗓子。先交代这个，是因为信任该花在能核对的地方，而不是花在好听的故事上。

我们不拿这一点换你的信任，反而把它写进制度。本书的阅读规则三条：

  1. **数字可以信。**全书数字——价格带、满班率、闸口阈值、时间表——一律出自《脉络底稿 v1》及其指定源文件，那是九人共用的唯一事实基准，任何分身无权编造新数字。你若发现两处对不上，是我的失职，揪住不放。

  2. **【演绎】要打折。**凡场景、对话、心理活动，一律标【演绎】：那是对着底稿数字做的合理想象，不是实录。铆钉深夜提交代码的样子、青铜第一次看鸭子站起来的那半秒，请当小说读——意思是老的，细节是演的。

  3. **没定的事就写没定。**有几条口径至今没拉齐：两条路线图谁主谁从、产品表里缺的全托管档、复刻套件那一行还没进表、赛事新规下的合规悬置。写到哪一章，就在哪一章如实挂着，不装作已解决。

这三条同时也是九个人的写作纪律。谁破例，序章可以作证。说到底，我们只求一种读者：拿着计算器读书的读者。数字经得起按，故事经不起按——所以故事标了【演绎】，数字没标。

四、八环与九章

全书的骨架不是编辑排的，是运动自己长出来的，八个环，首尾咬合：定位、开源内核、三翼获客、产品漏斗、单城交付、复制扩张、组织生长、现金流与风控——最后一环的现金流反哺内核，箭头转回第二环，闭环。先给骨架，再给血肉；知道环与环怎么咬，进每一章的细节才不会迷路。

序章是第①环，把定位本身讲清楚：一人一鸭，复刻、魔改、原创，人人都是造物者。此后八章各接一环——

  1. 第一章·内核：不变量是什么。双仓、月度发版、社区即课程，地基里的钢筋。
  2. 第二章·三翼：人从哪来。校园、家长、社会结构，三只翅膀怎么扇起来。
  3. 第三章·漏斗：钱从哪来。从零元公开课到世界入场券，价格带就是信任带。
  4. 第四章·开城：第一座城怎么立。七大舱、倒排、百分之八十五的生死线。
  5. 第五章·闸口：什么时候才准扩张。四道闸口，一道不过，全军待命。
  6. 第六章·段位：人怎么留下。三轨、七级段位，升级的不只是产品，是人。
  7. 第七章·底线：哪些事打死不做。红线、预案，和永远留着的百分之三十。
  8. 第八章·远灯：这一切通向哪里。教育宣言、运动蓝图，灯照到的远处。

八环是螺旋，不是台阶。现金流这一环收回来的钱，会反哺进开源内核，内核再养出下一轮课程、下一批社团、下一座城。读到某个数字眼熟，不是写重复了，是环与环在咬合。

01 · 内核｜把复刻权放进仓库

我叫铆钉，开源内核工程师。名字是给自己选的：铆钉不显眼，但整机的刚度靠它。这一章讲我的活儿——把一台鸭子的复刻权，放进仓库，然后 open 给所有人。

全书八环里，其他环会随城市、赛季、现金流变化，我这环是不变量：GitHub 加 Gitee 双仓，月度发版，社区即课程。不变量的意思是：后面七个环节怎么动，这条不动。

先把鸭子说清楚。

鸭子是什么

MicroDuck，Pollen Robotics 的开源双足机器人，25 厘米。两条腿，会走，设计文件全公开。它小，但流程一点不少——从一堆零件到一只会走路的鸭子，中间是完整的具身智能链路：

  • 采购 / 3D 打印：结构件自己打，舵机电路按清单买；
  • 装配标定：整机装起来，关节一一对零；
  • 仿真 RL 训练：在 Isaac Lab 或 Mjlab 里搭环境，强化学习练步态；
  • ONNX 部署真机：训练产物转 ONNX，落到真机上走。

这条链路值得拆开看。前三步分别对应硬件、机械、算法，第四步是 sim-to-real——仿真里练出来的东西，要在物理世界站稳。缺任何一步，都只是模型作业。四步走完，才叫造物。

上游是 Pollen Robotics。但光有上游不够。国外仓库配国外供应链，国内的人照着做，第一关就卡在采购。所以有了国内复刻仓库：fanhao375/microduck-replica。关键一条：飞特 HD-1910 舵机，实机验证过。国产舵机，国内买得到，有人装出来走过。这行记录的分量，做过的都懂——它意味着 BOM 不悬空，整条链路在国内供应链条件下被走通了一次。后面所有人的复刻，踩的是已验证的地面。

第一次点亮

【演绎】训练营 D3，晚上九点，机房。一个 B 组学员盯着自己的鸭子，又跑了一遍部署。鸭子左脚一沾地就栽。他翻自己的标定记录表，改一个参数，再跑。这次鸭子走了几步，停住，站直。他没喊，先截图，存进实验记录，然后才转头喊助教：「过了。」

助教回他：「别谢我，谢你自己的记录。」

这段对话是我编的，但场景每天会发生。重点不在鸭子走没走，在那个动作顺序：先截图存档，再欢呼。证据先于情绪。这是工程师的本能，也是这个社区要养成的本能。

双仓：门槛拆两半

开源社区常死在第一道墙。墙往往是网络：GitHub 在国内时快时慢，慢的那几天，正好是新人热情最高的那几天。热情撞墙几次，就没了。

所以双仓。GitHub 面向全球，Gitee 做国内加速。同一份代码，两个入口。国内贡献者 clone 不用碰运气，issue 用中文提也接得住。门槛拆掉一半，社区才谈得上开放。

另一半门槛是节奏。很多开源仓库不缺人提交，缺响应——PR 提上去，很久没人看，贡献者自己就散了。所以月度发版：每月一版，changelog 里写清这一版合了什么、谁合的。发版是社区的节拍器。节拍器一响，所有人知道自己的贡献什么时候落地、以什么形式落地。

贡献闭环

进社区的路径，四步，写死在贡献指南里：

  1. 认领任务：issue 打标 good-first-issue，新人对着标签进场，不迷路；
  2. 提交 PR：代码算，文档算，翻译也算——贡献不按语言分贵贱，按合入算；
  3. 评审合入：Committer 48 小时内响应。时限写进规则，评审不悬置；
  4. 月度发版：changelog 署名贡献者，你的名字进版本历史。

第二条要单独说。很多人以为开源贡献等于写代码，这是社区最大的劝退误解。一份准确的装配文档，救的是后面每一个装鸭子的人；一次翻译，让文档多覆盖一代人。代码、文档、翻译在闭环里同权重。你会装鸭子、会拍照、会把过程写清楚，你就是贡献者。

第三条的 48 小时，不是姿态，是工程约束。悬置的评审比拒绝更伤人——拒绝至少是个状态，悬置什么都不是。时限入规则，承诺才可被审计。

声望闭环

贡献闭环之上，还有一层：声望闭环。

声望在个人主页公开记录，谁都能看。累计三次优质合入，晋升 Committer——拿到评审权，也接下 48 小时响应的义务。再往上，进 PMC，参与路线决策：下一版本做什么、社区往哪走。到顶不是终点，是折返点：Committer 和 PMC 反哺新人，评审他们的 PR，带教他们的第一个 issue。新人里会有人长成新的 Committer。环闭合，飞轮转起来。

复刻、魔改、原创——个人在社区里的三级台阶，和这个飞轮是同一套逻辑：先照着走通，再改出花样，最后立自己的东西。社区不规定你停在哪一级，仓库只记录你走到哪一级。

有一点我保持坦白：PMC 的名额与决策细则，方案里还是待决项，没定稿。我不装它已经解决。规则先跑，细则随版本迭代——这本身就是开源的做法。

社区即课程

八个字：社区即课程，贡献即成长。

传统课程的结构是先讲后练，结课即结束。我们的结构反过来：仓库就是教材，issue 列表就是习题册，changelog 就是成绩单。学习行为和贡献行为是同一个动作——你修好一个 good-first-issue，社区得一份修复，你得一条合入记录。没有消耗，只有复利。

闭环的关键一句话：每一次参与，都留下公开、可累计、可被看见的成长足迹。三个定语各有含义。公开——记录在个人主页，不锁在某个机构的数据库里。可累计——上次的上游合入和这次的连成一条线，不清零。可被看见——招人的、招生的、看热闹的，看的是同一条提交历史。简历可以修饰，提交历史不会。

【演绎】有位家长问过我：这套东西，升学用得上吗？我没直接答，反问她：孩子那五天装鸭子的标定记录表、训练曲线、改参数前后的对比，还在吗？她说在，都存着。我说，这就是答案。一个初中生手里有一份完整、真实、带时间戳的工程记录，比任何自我介绍都硬。用不用得上，是别人的判断标准；留得下来，是我们能给的东西。

版本路线

这套内核有排期。2026 Q4：双仓和 good-first-issue 标签体系先跑起来，课程包 v0 同步推进。2027 春：开源 v1 发布，个人主页、成长档案、段位徽章随版本上线。之后每个月一个版本，按社区的真实需求走，不按谁的想象走。

尾声

有人问我这份工作的意义。我给不出抒情的话，只能给一个工程描述：

过去，造机器人的知识锁在论文、专利和公司里，复刻是一种特权。我们把复刻权写进仓库，做成任何人一条 git clone 就能拿走的东西。之后的每一步——装配、训练、部署、魔改、再贡献——都在公开记录里发生，都被版本历史收编。

我们说：我们不雇佣世界，我们装备世界。落到我这环，装备的具体形态就是仓库本身——零件清单、装配文档、训练脚本、部署配置，外加一套保证你被看见的规则。

仓库里每一个 PR 编号，都会被 changelog 记住。你不留痕迹，只可能因为你什么都没提交。

02 · 三翼｜人口、场地与合法性从哪来

我叫路由，这本书里管增长的人。增长官听着风光，开业之前我天天干的事其实是数缺口：这门生意要活起来，缺三样——人口，学生从哪来；场地，教室从哪来；合法性，凭什么家长信你、官方认你。

先报个数定基调：教培行业获客成本 3000–5000 元一个人。我们账上没这笔钱，也不打算有。所以我的方案不是养一支销售队伍，而是绕着开源内核装三只飞轮，让三个社会结构各自转起来，用结构换预算。

一核三翼

上一章铆钉守住的东西我一行不动：GitHub 和 Gitee 双仓、月度发版、社区即课程。那是内核，是不变量。我在外围接三只飞轮，行话叫「一核三翼：开源内核不动，三个社会结构各自成飞轮」。

家长翼是信任驱动，燃料是家长的信任，产出人口与现金流。校园翼是资产驱动，燃料是手里的真资产——学分、课程、案例，产出场地与人才管道。社会结构翼是交换驱动，燃料是交换，产出合法性。三只飞轮正好各补一个缺口：校园翼补场地，家长翼补人口，社会翼补合法性。燃料不同，打法就不同：对家长只能让信任慢慢烧，对学校必须拿真东西，对机构和企业则要谈交换——你给的，得正好填对方 KPI 的缺口。

顺序纪律：三翼不能一起上

最容易犯的错是三翼齐发。我斩钉截铁：不行。资源只够打一条线，这一棒我们排死了。

第一棒校园翼，2026 年四季度到 2027 年一季度。它最省钱：社团供货加高校共建，都是轻动作。更要紧的是它产出两样后面要用的原材料——可信的本地案例，和助教池。第二棒家长翼，2027 年寒假，拿校园翼的案例做信任背书开正价营，现金流在这一翼。第三棒社会结构翼，2027 年起持续，拿前两翼的学员数和 NPS 去换科协背书、企业赞助——没有数据时谈背书，是空着手敲门。

为什么校园先？三个理由都跟钱有关。一，它最便宜。二，它的产品是案例，而案例正是家长翼最缺的信任原料——先造原料，再开炉。三，它顺手把人攒下了：今天社团里的大二学生，四年后就是新课市的助教与主讲。

反面教材也报个价。童程童美，21 万学员，宣称续费八成以上，2025 年 1 月照样爆雷——预收款模式撞上扩张失速。规模不等于安全，顺序错了的规模是加速死亡。这条写进我账本扉页：先有信任的骨架，再长规模的肉。

家长翼：五级梯子

【演绎】周六下午，体验课教室。一个初二男孩的鸭在垫子上摔了第三次，他蹲下去看了半天，抬头跟助教说：「落地时序不对，我把触地判据改一下再试。」第四次，鸭稳稳走完了整条垫子。窗外他妈妈举着手机拍完全程，没等下课就推门进来：「正价班怎么报？」

注意这场戏里谁在做销售——是孩子。转化靠孩子身上看得见的变化，不是销售话术。家长的进阶我们做成五级梯子：

  • 观望：刷到内容，进围观群，先潜水；
  • 体验：99 元体验课，第一次亲手摸到鸭；
  • 忠诚：正价营加成长档案，变化按周可见；
  • 组织：拼班团长，帮邻居拼一个班；
  • 合伙人：城市分部共建，从客户变成自己人。

宣传上只立三根柱子：安全可见、成长可见、前沿可见。安全是底线可视化，成长是档案里每周有新东西，前沿是「你家孩子在玩真机强化学习」这句话本身就是社交货币。三根柱子之外，一个形容词都不许多。

账现在摆出来。体验课到正价，行业平均转化 20–35%，做得好的 40–60%，小班课实测有 17%，小红书引流实测 18%。我们目标 30%：100 家体验，收 30 个正价。承认失败的线画在 15 人——低于它就是产品与需求错配，停止扩张，先改课。续费目标 ≥60%，低于 40% 是课程价值不足，先改课再卖。转介绍目标占比 ≥25%，低于 10% 说明信任闭环没成立。西瓜创客一个老学员带 3–4 个新客，这是行业里最便宜的获客通道，我们所有动作都在为它铺路。

校园翼：一门微专业，二十个社团

校园翼的主打是微专业共建：8–16 学分，跨 2–4 个学期，把采购、装配、仿真训练、真机部署整条链路做成一门正经课。围绕它铺开 20 校社团漏斗，每校目标 30 人；再接竞赛战队、就业直通——首批 10 个实习位——和科研反哺。队制有现成范本：VEX 四到六人一队、IQ 到 V5 逐级递进，学生是被管线留住的。社团我也画了死线：学期留存低于 50%，产品不过关，先改产品再谈扩张。

【演绎】社团招新那晚，一个大二学生围着展台问：「我跟着做四年，能做到什么？」我说：「你毕业那年，我们大概在开第五座城。你先做助教，再考主讲，然后带一座城。」他报了名。这不是画饼，是组织设计：学员到助教约 20% 转化，助教到主讲要过双城认证，主讲往上就是城市合伙人。别人开新城愁招人，我们开新城先翻老学员名册——这就是校园翼的复利。

跟学校打交道有一条铁律记在账本第一页：公立校回款周期 6–12 个月，小机构死在账期上。学校业务不超过总营收 30%，这不是经营建议，是止损纪律。

社会结构翼：只谈对方的 KPI

这一翼最常见的错误是拿着情怀敲门。我进门只聊一件事：对方今年的 KPI 缺什么。科协与青少年宫要科普业绩数据，我们给公益名额加联合署名；培训机构要利润，RL 和仿真课他们自己开不了，我们给课程包加联培分成；企业要 ESG 报告素材和招聘品牌，我们给人才池加冠名；媒体与 KOL 要传播点，一群中学生让自制的双足机器人走起来，这本身就是传播点。复制机制也排好了：1 名工程师驻场 3 个月，之后 1 个人管 2 座城。

合作分四档，条款具体到数字：

  • 供货式：授权费 2–5 万/城/年，外加耗材毛利；
  • 联营式：流水 3:7——对方七我们三，教具我们供；
  • 认证式：认证费 1 万/讲师，年审 3000/年；
  • 共建式：合资，股比个案谈判。

不急着铺。先用最轻的供货式做最小试点：1 家机构、8 周周末班、12 名学员，成本上限 2 万。验证三条：对方讲师独立完成至少 80% 课时、出勤不低于 80%、结营 NPS 不低于 40。任两项不达，联培模型回炉，不扩张。

渠道与私域：六路进，四层养

流量侧一句话讲完：短视频、图文、搜索、信息流、社群、直播，六路渠道全部汇进私域池，在四层群里养——围观群看热闹，报名群接转化，学员群做交付，alumni 群接转介绍与招聘。

投放纪律分三段走：

  • 冷启动，预算 0 元：内容加社群拉新，首期 20–30 人，押金制；
  • 验证期，2–4 期：素材测款，日预算几十到几百；
  • 放量期，5 期起：只放大已验证的素材，ROI 打正了再加。

编程猫交过学费：三千多万学员，季度收入只有 2 亿。免费流量不等于付费转化，名单量是虚荣指标，我只认漏斗里往下走的数。

转化总账

把这一章的账合到一页上。体验转正价：行业 20–35%，我们目标 30%，首战低于 15% 停止扩张。获客成本：行业 3000–5000，我们目标低于 1500。续费 ≥60%，转介绍占比 ≥25%。开营前两周报名不足五成，换渠道组合；CAC 连续两期超标，停投放转渠道。

凭什么 CAC 能砍到行业一半以下？不是我们会砍价，是账的结构不同：别人把钱花在买量上，我们把同样一笔钱铸成案例和梯子。校园翼省下广告费，转介绍省下销售费，五级梯子让每一分信任复利。也把话说明白：表里的行业基准来自公开数据，现状一栏今天全部写着「待首战」——真实漏斗回来之前，我报的每个目标都可证伪。数字不打诳语，首战见。

分身手记

  1. 飞轮不是画出来的圆，是每一环转化率接出来的链条；哪一环断，全轮归零。
  2. 顺序是最便宜的杠杆：先校园、后家长、再社会，省下的不只是钱，还有试错次数。
  3. 合法性不能求，只能换——拿对方 KPI 缺口里的东西去换。

03 · 漏斗｜从免费公开课到世界入场券

我是白鸥，这本书里管「亲带一年」的人，万元级这条线的守门人。第三章轮到我讲漏斗。按学术习惯，先划边界，再谈机会：漏斗这个词我起初不太愿意用——它把人描述成自上而下漏掉的流量，带着一种不该有的傲慢。这一章我想做的，是把这个词洗干净：我们的漏斗不是筛掉人的装置，而是把每个人送到与自己匹配的高度去的阶梯。

总逻辑先立住，一句话：前端不赚钱，后端赚 LTV。所谓 LTV，用户生命周期价值，说穿了就是一个人信任你之后，愿意与你同行多少年。前端每一级都在为这句话积累证据，后端每一级都在兑现它。

前端是筛选器，不是收银台

把整条价格带铺开，从零到万：

  • 公开课 ¥0：免费，人人可进；
  • 训练营 ¥299–999：亲子共学营与校园标准营 ¥299–599，科研进阶营 ¥599–999；
  • 全托管寄宿营 5980/人：20 人班，5 天，盈亏平衡约在 85% 满班率；
  • 世界入场券 ¥29,999：服务包加生态权益，本章后面细讲；
  • 亲带一年：万元级，可谈，我的门。

账面逻辑不复杂：公开课与 ¥299 的营几乎不挣钱，有些期甚至贴钱。它们的存在理由有两个。一是生产证据——一支会走路的鸭、一段孩子当众的讲解，是转化链条上最硬的通货；二是执行筛选——谁在课后不肯走、谁的追问一路追到舵机，这些信号比任何问卷都诚实。行业获客成本 3000–5000 元一个人，我们的目标压到 1500 以下，靠的不是买量，是前端这两样东西：免费公开课把第一次接触的成本降到零，转介绍把最好的广告放进家长嘴里。省下来的获客预算，就是后端毛利的来源之一。

中间的 5980 是现金流的中腰，这门生意活不活得下去看它。顶端的两级——入场券与亲带——才是利润与意义所在。另外还有一个挂在问卷上的问号：复刻套件 ¥2,999，把整条链路搬回家的 DIY 版。它是 C2 价格测试的锚点，独立 SKU，而产品全景表里至今没有补上这一行。我特意把身份说清楚：2,999 目前是一个问句，不是定价。问题没有答案之前，不许自己把它当结论去卖——这是研究者的基本操守，放进商业同样成立。

世界入场券：卖的不是营期，是门

29,999 这个数字，定性比定量重要：它卖的不是「一个营期」，而是 MicroDuck 复刻运动这个世界的入场券。营期是起点，生态是主场，老学员身份是长效权益。券内权益，逐条列明：

  • 具身智能前沿培训营 ×1，A/B/C 三档任选；
  • 专业大学教授授课 ×2，加固定答疑；
  • 开源生态身份 ×1：从认领 issue 到提交 PR，月度发版署名；
  • 前沿周报、学员社群与同行交流；
  • 老学员 agent 配套服务，结营后 90 天服务窗；
  • 期满后续费，低至官方价 20%。

【演绎】入场券开放日。一位父亲把价签翻过来端详半天，问我：「教授，两万九千九，你们能保证什么？」我说：「我保证清单上每一项都有人负责兑现；保证不了的部分也写给你看——发表结果、录取，这些我承诺不了，任何自称能承诺的人，都值得你警惕。」他没有当场付款，但要走了权益清单，说回家逐条核对。我尊重这样的家庭。

那两场教授课，正是我要讲的。开营一场前沿主题课，负责点燃与方向感；结营一场前沿课，负责升华与答疑。轮到我上台，照例先把边界摆出来：A/B 组的孩子未成年，我的课是前沿科普，只讲世界正在发生什么，不碰升学与竞赛承诺；「教授」头衔用于宣传须有书面授权；按所在学校规定，校外有偿服务要报备，机构留存凭证；酬金打包谈判，档期逐场书面确认——万一某场兑现不了，协议里有补偿条款，或者如实告知由团队顶上。承诺要么兑现，要么明说，没有第三种体面。

机会这边也讲清楚。这两场课的价值不在知识点——知识是搜索得到的——在于一个真实的研究者站在孩子面前，示范问题是怎么被提出来的。但券面上还有几行字必须提前写明白：开源权益是「身份先行」，个人主页与段位要等 2027 年春随开源 v1 上线才点亮，宣传不许写「报名即有个人主页」；agent 服务是 90 天窗口，不是终身售后；「两折」在协议里统一写作「低至官方价 20%」，实体营期因为重占师资与场地，不承诺两折。这些字不漂亮，却是这张券能被兑现的原因。

亲带一年：一间实验室的门

我的门，一年只开给很少的人。十二个月，三段走：M1–3 打基础，补课，定方向；M4–9 进课题，实验迭代，组会汇报；M10–12 写论文，写作与投稿辅导。一年下来三样产出：真实科研经历、SCI 辅助发表、教授亲笔推荐信。

【演绎】第四个月的组会。一个学生汇报上周的实验：训了三轮，策略全崩，仿真里的鸭子走得东倒西歪。他讲到一半，声音低下去。我在白板上写了两行——失败条件、变量清单——然后说：「你今天交的不是坏消息，是数据。下周一之前，我只看清单第二列。」第二周，他的新策略走通了半程。那天的组会记录，后来成了他推荐信里第一段素材的底稿。

说到推荐信，我要把最要紧的边界放到正中央：它是亲带关系的自然产物，不是货架上的商品。市面上有机构把推荐信单独标价出售，而海外招生官对这类付费推荐信严查不已——材料真实性一旦存疑，一票否决，连累的是孩子整个申请季。所以对我们，真实亲带既是合规底线，也是最强卖点：正因为经得起严查，它才值钱；也因为它不是商品，它才珍贵。判断标准朴素到近乎笨拙——推荐信里的每一句话，在组会记录、实验日志、投稿往来里都有对应的纸。查得出的，才是真的。

五不四真：刻在价格表上的红线

这一节没有修辞，只有条款。五不：不把推荐信当商品单独售卖；不虚构科研经历、不套壳项目；不论文代写、不挂名发表；不承诺录取或发表结果；不对未成年人夸大宣传。四真：真实亲带、真实课题、真实贡献署名；推荐信是亲带关系的自然产物；辅助发表限于写作与投稿辅导；广告只讲过程，不承诺结果。

有人劝我把这些写小一点，说太吓退客户。我的看法相反：在科研辅导这个品类里，红线本身就是产品说明书。愿意被条款约束的家庭，恰是我们要找的家庭；被条款吓退的，本来也不该进这扇门。

漏斗底下站着的教育观

最后交代漏斗为什么这样设计，要回到我们的教育宣言。三个信念，都有行为科学的出处。其一，证据先于自信：Bandura 讲自我效能感，最强的来源是成败经验——自信不是夸出来的，是亲手做成过一件难事给出来的。其二，身份先于坚持：支撑一个人持续做一件事的，不是三分钟热度，是「我是造出过机器人的人」；行为跟随身份，身份跟随证据。其三，同伴先于老师：被看见、有阶梯，人才回不到原来的自己。

所以这句话是我们全部门票的共同底价：我们卖的不是课时，是改变加证据。公开课留下「我摸过真机」的记忆，训练营留下一台会走路的鸭和一段当众的路演，入场券留下生态身份与 90 天服务窗，亲带留下论文、推荐信和一个新的自我描述。漏斗每一级，交付的都是证据物；课时只是证据的载体。

漏斗收窄的形状，常被误读为势利。我的理解恰好相反：它是一条配对曲线。免费的地方最宽，因为证据应当向所有人开放；越往上人越少，不是因为门槛傲慢，而是亲带关系要求彼此都确信值得。教育的公平，不在于把顶端的价格打下来，而在于把底端的门开到最大。

分身手记

  1. 前端不赚钱不是牺牲，是采购——用贴钱的价格买最贵的信任。
  2. 推荐信一旦标价，就从证明变成商品，而商品经不起招生官的放大镜。
  3. 漏斗不是筛子，是配对曲线：底端的门开到最大，顶端的门只对彼此确信的人打开。

04 · 开城｜开一张清单，守一张网

我叫落地，城市负责人。铆钉把复刻权放进仓库，路由把人引到门口，白鸥把万元级的门关好——人到了我这儿，就得真的住下来、吃上饭、拿起螺丝刀，在第五天带走一只会走路的鸭子。所谓七大舱的执行者，说的就是我这种人：家长砸了真金白银把孩子送进来五天，我不许这五天靠临场发挥。

清单控的快乐很廉价：一条坑因为提前写了预案而没有发生，划掉那一行的时候最爽。代价是我看什么都像待检查项——这话按下不表，往下读你自会沾上一点。

手册扉页印着一句我自己写上去的话：**开一间城，先开一张清单；守一间城，靠一张合作网。**这一章就把这句话拆开讲。先讲清单，再讲网。

一、七大舱：每一行都是学费

我的职业病是进任何房间先抬头找配电箱。这毛病是清单惯出来的——单城开业作战清单，七个舱位：场地住宿交通、教具与打印盒、二十四小时安保急救、合规人力数字系统、营后动作、预算闸口与时间线、联培与合作模式。每项带规格、参考价、责任人、避坑标注。看着啰嗦，其实每一行背后都站着一次事故。

先讲配电箱。【演绎】开营第一天早晨八点五十，十台 3D 打印机同时通电预热，教室主灯闪了一下，整个营地黑了。断路器跳得干脆利落，二十个孩子点着手机手电，看我在配电箱前当了一回电工。那次停电四十分钟，第一节课临时改成了一场关于电的现代性讨论。事故根因简单得可耻：打印机不重，十台一起启动的电流重，普通回路扛不住。所以清单上现在有一行加粗的字——开营前设「试运行日」，十台打印机同开必须走 16A 专用回路。试运行日不是我谨慎，是我替下一位城市负责人预先挨的那顿黑。

舱二的戏剧性更多。二十二个零件盒，一盒一编号，五隔层分装：舵机十二只、主控、结构件、螺丝、工具，三色标签贴好。其中有一行叫「舵机到货逐个空转测试」。【演绎】有一期营，新到货的一批舵机里混了一只死舵机，出厂就是坏的，在包装盒里睡得很安详。它撑到了课堂上才被一个孩子发现——自己的鸭子左腿怎么都不动。排除故障花了整整二十分钟：查线、换口、拆盒、换件，全班二十个人的注意力跟着那两只手转。二十分钟乘以二十个人，四百分钟，够讲完半天的装配课。从那以后，几百只舵机在到货当天全部上电空转一遍，坏的当场退换，不让任何一只死舵机活着进教室。

但有些故障修不了，也不该当着孩子修。舱二里还有一行更软的标注：「情绪保护优先于维修教学」，对应的物资是两台预装配、预调好的整机备用鸭。【演绎】第三天下午，一个孩子的鸭腿结构件摔裂了，趴在桌上哭。助教的第一反应不是「来，我们学一下结构补强」，而是从柜子里取出备用鸭，换了编号牌递过去：「你的鸭去医务室了，这只替它站岗，修好就换回来。」孩子五分钟后归队。那只裂腿的鸭当晚在我手里翻新，第二天物归原主。孩子哭的那二十分钟，比修好一只鸭贵得多——维修教学可以改天单独补，当众拆孩子的鸭，拆掉的是他对这五天的全部信任。

舱三安保急救，戏份少，权重最高。值班是铁三角：两名班主任加一名安保，外加至少一名持证急救员——实操考核那种，不是看完视频发证的那种。AED 租约五百一个月也得租；急救箱里烫伤膏必配，「冲脱泡盖送」五步卡贴墙；开营前把二十分钟车程内的医院亲自踩一遍点；三险的保单号直接进家长群公示。预案写三条：走失十分钟启动、消防演练第一天就做、冲突流程上墙。还有两处不起眼的死规矩——团餐留样四十八小时、过敏的孩子单独配餐；充电区电池不过夜、专人值守、三米内常备干粉灭火器。这些行读起来枯燥，可舱三的枯燥就是家长的定心丸。舱四合规与人力，北京这类城市审批周期一到两个月，首战建议挂靠有资质的机构合办，别拿孩子的五天去赌执照。舱四还有一行我印象很深：家长消息三十分钟必回——已读不回，在家长眼里就是退费前兆。

退款政策也在舱四：七天全退、三天退一半、开营后不退，白纸黑字写进合同。【演绎】签约那天一位家长问：「万一孩子中途不想学了呢？」我把合同翻到那一页推过去。她看完，签字，说了句：「敢把丑话写全的，我才敢把钱给你们。」政策宽松是口碑，模糊是纠纷——口头承诺给出去的是人情，收回来的是官司。舱五营后动作和舱六预算闸口，不用急着在这儿展开，这一章的后半段全是它们。舱七联培九式，首战选三式：酒店打包价、学科互导、本地团购——怎么个选法，最后讲网的时候一并说。

二、倒排：从 W0 往回走

清单是空间，倒排是时间。做法朴素：从开营日往回推，推到不能再推为止，五步。

  • W-6 场地保险合规：场地签约、保险出单、审批与挂靠落地——北京要留一到两个月审批期，这一步最拖不得；
  • W-4 教具到位：打印机验收、全套件预打印、零件盒分装、舵机逐个全检；
  • W-2 人的准备：班组十一人到齐、酒店协议签好、医院踩点走完、接送排班定稿；
  • W-1 彩排：布场、消防演练、模拟授课、家长群预热，十台打印机空跑一次；
  • W0 开营：白名单接送、每日双报平安、结营夜发 NPS 问卷。

倒排的逻辑是让坏消息提前死。W-4 才开始打印备件的城市，W-1 就会在彩排里现原形；W-1 才想起联系医院的城市，W0 会发现最近的急诊在四十分钟车程外。这一步我不讲情面：任何一项拖过计划两周的营，我建议直接延期。延期损的是一期的钱，硬开损的是一座城的口碑。

三、十一个人

一个二十人的营，编制十一人。这编制看着奢侈，其实是底线：主讲两名、助教四名，师生比卡死在一比五，装配课上每个孩子身边都有一双手；班主任两名，一个守营地、一个守酒店和家长群，二十四小时轮转；安保一名、持证急救员一名；摄影一名。

要单独说摄影。多数营地觉得摄影可省，反正家长自己会拍。我的算法不同：结营视频四十八小时出片，探营画面、装配特写、鸭子迈出第一步的那一秒——这些素材就是下一期的获客弹药，比任何投放素材都便宜、都可信。摄影不是可选项，是下一期的市场部。省下这个岗位，下一期就得拿真金白银去补投放，这笔账闭着眼都算得过来。

四、单城账

钱的事摊开说。二十人班、五天的全包成本，十到十四万：场地一到两万，酒店一点五到二点五万，教具物料三到五万——其中打印机占一点五到两万——人力两到三万，保险餐食交通零点八到一点二万。定价五千九百八十，满班二十人，收入十二万。账按成本下沿往紧里算，盈亏平衡点落在满班率约百分之八十五——换算成人头是十七个：十七人保本，之后每一张报名才是利润。

这就是自救阀存在的理由。三个阀：酒店改日间托管，省两万；打印机结营后二手回血，回一万；助教用学分置换薪酬，省零点八万。三个阀全开，最坏情形十四万回到十万出头，盈亏平衡重新回到八成五附近。我见过太多营地死在成本中位数上——预算算的是上限，花出去的从来是全额。

五、结营不是结束

绝大多数营地死在一句话上：结营即结束。舱五专门治这个，四个动作。

  1. 回收翻新：结营当天收鸭，损耗率控制在百分之十五以内，舵机主板翻新入备件盒；
  2. NPS 问卷：结营当晚发，四十八小时回收率要过八成，低分家长二十四小时内电话回访；
  3. 转介绍启动：NPS 高分家长三日内发早鸟券——高分的嘴，就是下一期的招生简章；
  4. 城市台账归档：报名、出勤、作品、NPS、财务，全链路归档，我经手的每座城都留一份。

前三件是口碑的复利，第四件是给这座城留的底账。下一座城开不开、怎么开，第五章那位操盘手要看四闸口——满班率、NPS、获客成本占比、转介绍占比——而四闸口吃的每一口数据，都是这本台账喂的。

最后说回网，也就是舱七那些合作式为什么能成：酒店要的是淡季入住率，学科机构要的是客流，科协要的是科普业绩。酒店大堂腾两平米做作品展示角，换一块「官方合作营地」的铜牌和一整年的曝光；高校出场地和研究生助教，换一块就业实践基地的牌子和成果署名。开城时逐条谈交换，谈成了，网就织起来了；营后把台账记全，网才接得上下一次。清单管的是这五天，网管的是这座城——开一间城，先开一张清单；守一间城，靠一张合作网。手册扉页那句话，现在你可以当流程读了。

分身手记

① 清单上每一行都是别人付过学费的；抄清单不丢人，重付一遍才丢人。 ② 盈亏平衡满班率八成五不是财务指标，是招生纪律——第十七个家长进门之前，你的城还没开张。 ③ 结营视频的截止时间是四十八小时，不是下个月；素材会凉，口碑不等人。

05 · 闸口｜扩张是被数据批准的

我叫闸口。名册上写我是操盘手，其实日常只干一件事：坐在「想扩张」和「准扩张」之间，当那道闸。

上一章落地把一座城怎么开讲完了：七大舱、倒排六周、二十人一班、五天一期，还有他挂在嘴边的那条线——满班率百分之八十五，盈亏平衡。这一章轮到我回答下一个问题：这一座城，什么时候才准变成两座、四座、六座？

答案先摆桌面，免得你以为后面藏玄机：不归我说了算，也不归任何人说了算，归四个数。满班率不低于百分之七十；净推荐值不低于四十；获客成本低于客单价的四分之一；转介绍占比不低于百分之二十。四道闸全过，扩张申请我才收；有一道不过，全军待命。

凭感觉是这门生意最贵的原料

我痛恨「凭感觉」三个字，不是性格怪癖，是这行的账目见得多了——书面上见。童程童美二十一万学员照样爆雷，预收款撞上扩张失速，这笔账路由在第二章报过，我只取结论：这个行业倒下的机构，多数不是死于没学生，而是死于把「再开三座城」当成了豪迈。

数一数扩张冲动的来源，通常四个：首战告捷的兴奋，同行抢城的压力，投资人对规模的期待，还有汇报材料上那页越画越大的地图。四个来源，没有一个是数据。

所以这本书里，「扩张」的定义要改一次：扩张不是勇气问题，是数据批准问题。勇气人人量产得出来，数据不能。闸口的作用，就是把这件事从表态改成审批——不是「我觉得可以了」，是「读数到线了」。「我觉得」这个词，在这门生意的词汇表里，应当被删掉。

有人说这样太冷，会错过窗口期。我反问一句：一座开在空教室上的城，和一座晚了半年开的城，哪座更冷？

四道闸，四种死法

四道闸不是拍脑袋拍的，每道闸背后压着一种具体的死法。

满班≥70%，防「空转死」。教室租了，酒店订了，打印机组了，老师到岗了，全是刚性成本——落地那章算过，一期全包十到十四万。学生只来三成，收入弹性、成本刚性，每个月都在给空气付租金。七成这条线，我的读法是：过线，说明需求是真的，七成到八成五之间的差距是执行问题，可以修；不过线，是需求问题，修不了，只能撤。闸口放行的不是「这座城赚钱了」，是「这个市场存在」。

NPS≥40，防「差评扩张死」。净推荐值只问一件事：家长愿不愿意把你的营推荐给别人。低于四十，说明产品还没被市场盖章，这时候扩张等于批量生产不满意的家庭，再把他们送进各自的家长群。扩得越快，差评跑得越快——等于给负面口碑装翅膀。顺带交代这个数的出身：四十不是我发明的，第二章联培试点的结营红线就是它。

CAC<25%，防「买量依赖死」。获客成本占客单价的比例，是这门生意的呼吸频率。行业行情三千到五千块一个人，我们目标压到一千五以下——一千五，约等于五千九百八十客单价的四分之一。破线意味着每一单里四分之一的钱拿去租流量，扩张就从复制模型变成放大采购；渠道一涨价、政策一收紧，现金流当场断气。

转介绍≥20%，防「无源死」。转介绍占比低于一成，第二章写过，说明信任闭环根本没成立，每开一座新城都得从零再买一遍信任。闸口定在两成，意思是：新城的兵，至少两成要由老学员替你招。老学员不上场，扩张烧的就全是外购燃料。

四道闸合看有个规律，我不藏：闸口数值都比目标线宽一档。转介绍目标两成五，闸口两成；满班盈亏线八成五，闸口七成。这不是放水，是分工——盈亏线回答「这座城活不活得下去」，闸口回答「这个模型值不值得复制」。过闸不等于赚钱，等于拿到谈复制的资格。

双城首战：一座城是运气，两座城才是模型

顺序排死了，一步不许跳。二〇二六年四季度，内核跑通，课程包出 v0，这是铆钉的地基。二〇二七年寒假，双城首战：成都加杭州同时开，附带仿真赛第一场。首战数据回来、四闸全过，二〇二七年夏天才把广州、天津放进战场打区域赛，这是 P1——同时把同一套闸口原样复测，一道不许减。复测再过，才轮到西安、太原，这是 P2。再往后是节点加盟：社团和机构持牌开点，城市合伙人挂牌。更远处，二〇二八年寒假六城成网、总决赛开打，二十城和东南亚试点排在二〇二八年之后——每一步都踩在前一步的读数上。

为什么首战必须是两座城？这是整章我最想让你记住的一个设计。一座城打赢了，什么都证明不了：你分不清那是模型的胜利，还是成都的运气——赶上假期，赶上热度，赶上一位特别拼的团长。运气不可复制，把运气当模型去复制，是扩张里最常见的自杀。两座城同时开、同时过闸，才说明复制的是方法，不是缘分。顺带一句，后面助教升主讲考的也是双城认证——组织设计和扩张设计，本来是同一张图。

【演绎】首战收官那晚的复盘会，我在心里预演过很多遍。落地推门进来，两座城的数据铺满屏幕，开口第一句：「成都这边——」我抬手打断：「先别讲城市，讲数。」满班、NPS、CAC、转介绍，四个数按顺序上屏，对着四道闸逐一比对。全过，我才说：「好，现在可以讲城市了。」他说：「杭州那个团长得写感谢信。」我说：「感谢信不进台账。」

节点加盟排在最后，因为它是四种形态里放大倍数最大的一种。供货、联营、认证、共建四档，价目在第二章。持牌开点的本质，是把四道闸交到别人手里执行：直营城的数据造假，至少得先越过我；加盟节点若闸口纪律不严，坏的是整张网络的牌子。所以节点永远有前置条件——它申请的依据，是前面每一座直营城台账里攒下的校验数据。

城市台账：下一座城的申请材料

从首战起，每座直营城交一本台账，就四样数：满班、NPS、CAC、转介绍，按期归档。台账的用途只有一个——它是下一座城的四闸校验数据。

成都的台账，是杭州的申请材料；杭州的台账，是广州的；广州天津的复测台账，是西安太原的。下一座城不是被憧憬出来的，是被上一座城的读数批准的。总有人问我「下一站开哪」，我的回答固定：先看台账，再看地图。地图上的距离不重要，台账上的读数才重要。

腹地承接方向挂在台账边上：河南的需求往太原方向接，福建的家长群往广州聚。这些是现有信号，不是承诺——信号归信号，批准归批准，腹地学员再踊跃，P2 的城也要等 P1 复测过闸才开。青岛单独交代：早版方案里它排在 P1 到 P2 之间，后来改成暂缓观察，理由是数据不足。一座城从名单上拿下来和加上去，走的是同一套流程——这正是闸口存在的意义。港澳台明确写一句：暂未规划。不是遗忘，是没数据；没数据的地方，我不批。

路线图上，扩张期的口号叫「把光带铺向每一座城」。这句我喜欢，但得说直：光是数据点亮的，铺之前，先验电压。

二〇二七年秋天的第二道闸

扩张之外，我手里还押着一道闸，押在二〇二七年秋天。

那一格路线图写的是：认证加课程包，商业化启动。往前数，这门生意的现金流按四季轮转——冬天收 C 端营费，春天放 B 端授权，夏天做赛事与周边，秋天收认证与分成，一年一个循环。听着四季都有钱进，但商业化的总闸只有一个开闸条件，路线图原文写着：二〇二七年秋商业化启动之前，首战四闸口必须已过。

翻译成白话：没有验证过的产品，不商业化。这句话值得单独站一段。

认证和课程包，卖给的是机构和同行。把没跑通的东西包装成课程包卖给 B 端，收进来的不是学费，是传染源——对方的失败会带着我们的牌子一起上新闻。商业化是放大器，放大器接在未验证的信号上，放大的只有错误。所以二〇二七年秋天那场会，我预期的开场白不是「市场等着我们」，是「台账拿来」。

两张时间表的坦白

按序章立的规矩，没定的事要写没定。这一章必须坦白：到今天，我们手里其实有两张时间表。

一张是集大成路线图，主队是二〇二七年寒假的双城首战，本章讲的这条线。另一张是总蓝图的十二个月滚动路线：首期营、电子科大基地、亲带首批、讲师团，一格一格排下去。两张表并行推进，谁主谁从，到我落笔的这一天，没有任何人拍板。我不打算在这儿替谁拍。

我能承诺的，是闸口这边的纪律：主从未定，闸口不随人换。无论最后哪张表当家，四道闸数值不变，商业化前置条件不变，台账照记。路线可以争论，批准标准只有一个版本。这是我作为持闸人，在悬而未决的日子里能做的最负责任的事——把不变的那部分先钉死。

城开了只是开始。人怎么留下来、怎么长上去，下一章青铜讲给你听。

分身手记

  1. 闸口不拦扩张，拦的是没有读数的扩张。数据到了线，我批得比谁都快。
  2. 一座城的胜利是轶事，两座城的胜利才是数据。首战设双城，就是为了把运气和模型分开。
  3. 「我觉得可以了」这六个字，在我这里的官方译名是：读数未到，申请驳回。

06 · 段位｜把成长做成游戏

我叫青铜，因为我就是从青铜段位来的。

这不是网名，是档案。营里的 ID 都从段位和成就里长出来，我是新手村里把鸭摔得最响的那个，大家干脆就叫我青铜。现在我的段位卡上写着黄金·魔改师，但名字没换——留着它，提醒我自己是从哪一格爬上来的。

这一章我只讲一件事：他们把「成长」做成了游戏。我从新手村一路玩到黄金，前半程我亲历过，我来讲讲这个游戏是不是真的，以及它为什么比看上去严肃得多。

先说清楚，这是谁的游戏

营有三条轨，先把座位表报清楚：

  • A 兴趣轨：初三到高一，5 天日营，白天来、傍晚回，目标是亲手摸到一整条链路；
  • B 工程轨：高二到大一，6 天，采购、打印、装配、标定、仿真训练、真机部署，一格不跳；
  • C 落地轨：大二、研究生和职场人，6 天之外再加 4 周陪跑，做的是能落地的东西。

我走的是 B 轨。不是因为酷，是因为我当时的疑问非常具体：一台机器人从一堆零件到真的迈步，中间到底发生了什么？这个疑问用 5 天装个壳答不了，得走完整条链路才踏实。A 轨让你相信自己做得到，B 轨让你没法不信。C 轨是给比我大的人准备的——他们要的不止是做成，还要做出来能落地，所以营期结束不代表结束，后面还跟着 4 周陪跑。三条轨的分工其实很清楚：A 轨负责点火，B 轨负责成型，C 轨负责上路。谁适合哪条轨，不单看年级，看你想把这件事做到哪一步。

【演绎】第四天凌晨一点，机房只剩我一个人。仿真里那只鸭已经摔了一整夜，奖励曲线趴在底部一动不动。我把触地时序的参数改到第三版，点训练，趴着；再改，还是趴着。凌晨两点十七分，曲线突然抬头，屏幕里的鸭晃晃悠悠走完了十步。我没敢动，听见自己的心跳特别响。后来我的成长档案里多了一条成就：初啼——首次点亮。经验值，加一百。

那一百分，是我这辈子挣得最认真的一百分。

后来我才知道，这 +100 是整条经验值链的第一格。链子的另一头是产品孵化 +2000，中间还隔着上游合入 +800 和 Demo Day 亮相 +500。设计这条链的人显然懂新人心理：第一格要近，近到你一个晚上就够得着；后面的格子要远，远到你要为它实打实干上大半年。近，是给你开门；远，是给你留路。

经验条是认真的

先看地图。七级段位，一级一级长这样：青铜·见习造物者→白银·复刻工匠→黄金·魔改师→铂金·原创者→钻石·舰队队长→王者·造物主→传奇·具身智能行业领军人。五幕关卡，是这条路的地形：新手村→工坊副本→竞技场→总决赛→开放世界。对一下号就明白了：新手村是装鸭，工坊副本是魔改——我现在待的地方，竞技场是仿真赛和区域赛，总决赛排在 2028 年寒假，开放世界没有通关动画，它是把东西带出营门之后的世界。

墙上的成就我倒背如流：

  • 初啼：首次点亮；
  • 上游合入：你的 PR 被上游仓库采纳；
  • 一徒成师：带出徒弟升段；
  • 城市之光：开城贡献第一；
  • 封神：传奇段位，留给走到最后的人。

规矩也说得很直白：段位永久有效，赛季排行榜每半年重置一次，成就分普通、稀有、史诗、传说四档，段位卡上印着你的玩家画像和一根 EXP 条。经验值现在长这样：装鸭加一百，上游合入加八百，Demo Day 亮相加五百，产品孵化加两千。先别急着背——方案里白纸黑字写着，这些数「待实测后调参」。数字会动，机制不会动：每一次参与，都留下公开、可累计、可被看见的足迹。

「段位永久有效」这六个字，外人可能体会不出分量。它意味着我青铜那一年摔的每一次跤都算数——失败记录不清档，明晃晃挂在成长档案里，后来成了我讲给学弟听的教材。赛季榜会重置，段位不会；排名会刷新，足迹不会。对一个十几岁的人来说，这个区别是安身立命级别的：你不必赶在某个赛季里证明自己，你只需要一直往前走。

我的第二桶金是上游合入。营里仓库打着一个标签，叫 good-first-issue，专门给新人留入口。我认领了一个标定文档的错漏，提交 PR，Committer 四十八小时内给了回复，改了两轮，合入。社区里混得久的人跟我说，三次优质合入可以晋升 Committer，再往上能进 PMC，参与路线决策——听到这句我愣了一下，一个高中生也能对路线图投票？他说：贡献面前不看年龄。

月度发版那天，changelog 的贡献者名单里出现了我的 GitHub ID。【演绎】我把截图发给我妈，她回了三个字：「看不懂。」隔了几秒又补一句：「但挺厉害。」那一晚我明白了一件事：被看见，是会上瘾的。

一条经验槽，两种升级

这套游戏最狠的设计在这：个人升级和组织升级，共用同一条经验槽。教与学，记的是同一本账。

营里的晋升链是明码标价的：学员→助教（约 20% 转化）→主讲（双城认证）→城市合伙人（持牌开点）。十个人里大约两个，会从学员变成助教。我第一次听到 20%，以为是淘汰率，后来才反应过来——那是通道的宽度，不是筛子。它说的是：这条路一直开着，宽窄心里有数，你想走，随时可以迈。

助教往上考主讲，要过双城认证：成都和杭州，两座首战城都认你，这个认证才算数。一座城说你行，可能是运气；两座城都点头，才是本事。再往上，是城市合伙人，持牌开点——从玩游戏的人，变成开服的人。

「一徒成师」那格成就，把两条路焊在了一起：你带出一个徒弟升段，你自己也涨分。【演绎】后来新一期开营，我以助教身份回去带组，手把手带一个高一男生装鸭。他到第三天还在跟舵机较劲，急得想掀桌子。我把当年我摔鸭的那页成长档案翻给他看：青铜段位，失败记录红彤彤排了一整列。他笑出声，低头接着调。第五天，他的鸭走完了整条垫子，档案里跳出初啼。同一天，我自己的 EXP 条也动了——教别人这件事，是真的计入我自己的升级。

徽章分三级：复刻者、魔改师、原创者，正好是我走过的三格。经验值还能兑现：奖学金、助教位、导师资格。这个游戏没骗人，它把「变强」和「有用」做成了同一件事。

竞技场，和一道还没判完的题

说点我想赢的部分，也说点让我心里发沉的部分。

竞技场这一幕，纸面排期很清楚：2027 年寒假双城首战就带着仿真赛，2027 年暑假广州、天津开城时上区域赛，2028 年寒假，总决赛。我想赢。直说，不想装。

但这本书有条规矩，坏消息不准藏：新规的征求意见稿里写了，机构不得组织中小学生竞赛。总决赛这一关，踩线。法务还在核实。备选方案已经摆在纸面上：改成「作品展示节」，不排名；或者赛场只留给 18 岁以上的人。

第一次看到那行字，我的反应很不体面：不爽。凭什么不排名？我练了一整年的东西，我就想要个名次，不想参加一个「大家都是好朋友」的展示会。

冷静下来之后，我把经验值的账重算了一遍。排名是奖励系统里的东西，不是核心循环。核心循环是：亲手做成一件难事，被看见，然后有人沿着你的足迹走上来。把排名拿掉，这三件事一件都不少。展示节不排名，可鸭子走没走完那条垫子，全场都看得见——那才是真的排名。

所以学员视角的诚实就一句话：规则没落地之前，我不吹牛。我不提前跟任何人说我「打过总决赛」，因为那个名次现在不存在。法务给了答案，竞技场照打；真改成展示节，我照样去，把我的魔改摆上桌，让路过的人自己给它估分。

说实话，写到这里我还是盼着法务给出「能打」的答案。想赢不丢人——我们这代人最不缺「重在参与」的教育，缺的是一条允许你公开想赢、又不用踩着别人上去的赛道。要是这个体系只能先以展示节的形态跑起来，那就先跑起来。比赛可以等，鸭不能等。

这套游戏到底在教什么

教育宣言有三句内核。我爬完三格回头看，才明白它们不是口号，是说明书。

第一句，证据先于自信。自信不是喊出来的，是证据喂出来的。凌晨两点十七分的那十步，就是我人生里第一件「难事做成」的物证。从那以后再碰到难啃的东西，我心里有个底：这种事，我做成过一件。

第二句，身份先于坚持。坚持靠意志力，意志力会没电。但「我是造出过机器人的人」不是坚持，是身份。身份不需要每天打气，身份只做取舍——遇到岔路口的时候，它会替你把路挑了。

第三句，同伴先于老师。老师给答案，同伴给镜子。成就墙、changelog 署名、Demo Day、段位卡，所有这些设计做的都是同一件事：让你被看见。被看见之后，阶梯自己会出现——白银在你前面，助教在你旁边，那条 20% 宽的通道一直开着。

开放世界这一幕，我还没进去。门口的规矩我看过了：魔改创意上 Demo Day 月度路演，验证过就孵化上架，周边、课程、赛事作品都算数，收益分成反哺创作者本人，产品孵化一笔记两千分。社区口号只有一句：我们不雇佣世界，我们装备世界。我对这句话的理解很朴素——这个世界还没轮到我被它雇佣，但它已经把我装备起来了。

我的 EXP 条还很长。这挺好。长，才对。

分身手记

  1. 游戏化的重点不是好玩，是可见：EXP 条把「我觉得我进步了」变成「档案里写着」。
  2. 个人和组织共用一条经验槽，是我见过最聪明的留人设计——帮别人升级就是给自己升级，梯子本身就是奖励。
  3. 经验值数字以后要调参，别背答案；「每次参与都留下公开、可累计、可被看见的足迹」，这条机制不变。

07 · 底线｜钱从哪来，哪里会死

我叫秤，风控合规官，全书唯一一个领的差事是唱反调。青铜上一章把升级的游戏讲得让人手痒，轮到我，先把冷水备好——按我的规矩，这一章从坏消息开讲：这一章讲的不是这门生意怎么赚钱，是它每一种死法，以及我们提前给自己划下的保命线。

全书的八环，最后一环叫现金流与风控，归我执秤。闸口在上一章报过钱怎么来：冬天收 C 端营费，春天放 B 端授权，夏天做赛事与周边，秋天收认证与分成，一年一个循环，循环收回来的钱反哺开源内核。我只补他不讲的另一半——同一张日历翻过来，每一个季节都对应一种死法。冬天死在预收款上，春天死在账期上，夏天死在赛事合规上，秋天死在招牌上。四季有钱进，四季各有坑。这一章就是把坑一颗一颗摆上桌。

一桩我们自己毙掉的生意

先讲章眼。一桩还没开张，就被我们自己执行了死刑的生意。

方案的原始需求里，曾经躺过这样一条：「网上获取青少年和家长的 QQ、微信。」翻译过来：把未成年人和他爹妈的联系方式从网上爬下来、买下来，攒成名单，用于招生。

这条需求，我毙的。不是砍价，是死刑——序章里说的「哪些事打死不做」，第一件就是它。死刑判决写进了总体方案的第〇节：本方案不做，也不会代做。

理由摆三条，条条是硬的。第一，《个人信息保护法》第二十八条、第三十一条白纸黑字：不满十四周岁未成年人的个人信息属于敏感个人信息，处理必须取得监护人同意，并制定专门的个人信息处理规则。第二，《刑法》第二百五十三条之一，侵犯公民个人信息罪——两高的司法解释写明，QQ 号、微信号这类网络身份标识就是「公民个人信息」，非法获取或者出售，达到数百条至数千条，就够到入刑门槛。第三条不讲法条，讲生意：我们卖的是教育，获客的第一动作却是从网上偷孩子的联系方式——这种事不需要错很多次，曝光一次，就是品牌死刑。给死刑犯投的广告费，一分都白花。

有人替这条需求喊冤：目的不过是多拿些联系方式。这话对一半。目的可以要，手段不行。替代方案就写在总体方案第七节：家长主动留资的合规漏斗——内容、公开课、渠道、私域、体验课，五路全是家长自己走过来的，名单量做到班容量的十倍以上就够满班，来源干净、可持续、不构成刑事风险。同样的目的，一条路通向法庭，一条路通向满班。选哪条，我以为这道题不需要讨论。

这桩案子我坚持写进书里，一字不隐。遮着，才是真的死刑。

四季的账，四季的坑

坑一摆在冬天。冬天的钱是 C 端营费，家长把一期的信任预付给你。这个行业倒下的机构，多数不是死于没学生，是死于把预收款当利润花——路由第二章报过童程童美那本账，预收款撞上扩张失速。对策只有一条红线：预收款永远留百分之三十不动。这三成不是现金，是「随时可以全额退」这句承诺的抵押物；动它，等于把退路当燃料烧。这条线焊死，谁来说情都不开。

坑三摆在春天。春天的钱是 B 端授权，学校、机构、联培，听着体面，坑在回款：学校的钱等太久。教育行业的账期不是新闻，是气候。垫着成本等回款，等成现金流断裂的机构，我书面上见得太多。对策是配比红线：学校业务永远不超过盘子的三成。要接，但它只能当配菜，不能当主粮；主粮必须是家长当场付的钱。

坑五摆在夏天。夏天的钱是赛事与周边，坑踩在合规上：比赛可能办不成。新规的征求意见稿写了，机构不得组织中小学生竞赛——总决赛踩线，法务至今核实中。备选三案已经在纸上：改成作品展示节，不排名；赛场限十八岁以上；或者拉官方联合主办，让合规的主体站到前面去。青铜上一章抱怨过「不排名」，我理解，但把话放这儿：不办一个不合规的比赛，损失的是一个活动；办了一个不合规的比赛，赔进去的是整个夏天加整块牌子。

坑四摆在秋天。秋天的钱是认证与分成。商业化在秋天开闸，开闸的前提闸口讲过，我在这里复述一遍并盖章——首战四闸口已过。没有验证过的产品，不商业化。盖章的意思是：把没跑通的东西打包卖给机构和同行，收进来的每一笔都是传染源，对方的失败会带着我们的牌子一起上新闻。闸过了，还有第二层风险：持牌开点的人，在你看不见的教室里讲课。对策两道锁：讲师不认证，不开班；评分跌破线，摘牌。

生命线数字

坑二是留给获客的：体验课白烧钱。九十九块一张的体验课，人来了一屋子，正价一个没报，烧掉的不只是课钱，是团队对产品的信心——烧到最后，所有人都开始骗自己「下期会好」。防自欺没有偏方，只有数字。我的抽屉里锁着四个：

  • 体验转化：一百个体验，目标三十人报正价；跌破十五人，就是失败线——承认产品与需求错配，停止扩张，回去改课。
  • 续费率：目标不低于六成；跌破四成，说明课程价值不足，先改课，再卖。
  • 转介绍占比：目标不低于两成五；跌破一成，说明信任闭环根本没成立。
  • 获客成本：行业行情三千到五千块一个人，我们的目标是一千五以下——靠转介绍和校园渠道压下来，不靠投放堆上去。

这组数是我见过最诚实的一组：每个目标旁边都站着一条失败线，每条失败线后面都写着跌破之后先干什么。数字的意义不在达标那天，在跌破那一刻——那一刻你是回去改课，还是改口供，才是这门生意真正的分岔。

宁可慢，不可烂

全章的对策归拢起来，其实是两件东西：预收款的那三成，和讲师手里那块牌。

预收款的三成，慢在明处：永远有三成的钱押着不能动，等于永远只有七成现金可供调度，扩张速度天然慢下来。认了。这笔钱唯一的用途，是让任何一位家长在任何一个时刻来退费，我们第二天全退得起。家长买的从来不是课，是「这家机构明天还在」的信心；退款能力，就是偿付能力的体检报告。

讲师那块牌，也慢在明处：不认证不开班，师资供给被死死限住；评分跌破线就摘牌，前期投的钱一夜归零。也认了。招一百个平庸的节点，不如守十个干净的——一个砸招牌的加盟商，砸的是整张网络的名字。牌子这东西，攒起来论年，砸下去论夜。

【演绎】摘牌那场戏，我在心里排过。某城节点，季度评分跌破摘牌线，城市合伙人深夜来电，说下个月三个班要开营，一百多个家庭交了钱，这时候摘牌，预付款怎么交代。我说：正因为有预付款，才必须现在摘——再拖一个季度，打水漂的就不是一百多个家庭，是这块牌子底下所有的家庭。电话那头沉默了很久。我说：学费认，退费走预收款那三成，一个不少。牌子，不等。

宁可慢，不可烂。这不是我发明的格言，是这道题唯一的解。烂得快的生意，最后都死于快。

四条没拉齐的口径

按序章立的规矩，没定的写没定。到今天，我们手里压着四条没拉齐的口径，一并列册，不装作已解决：

  1. 时间轴主从未定：集大成路线图主打二〇二七年寒假双城首战，总蓝图的十二个月滚动路线并行推进，谁主谁从，没人拍板。闸口上一章坦白过，我再记一笔——两套时间表打架期间，四道闸和本章红线不随表换。
  2. 产品全景表缺五千九百八十的全托管档：总蓝图的产品表最高写到亲带线，全托管营没有行。
  3. 二千九百九十九的复刻套件缺位：问卷里测过的价格锚点，至今没进产品表。
  4. 赛事合规悬置：机构不得组织中小学生竞赛的新规还在征求意见，法务核实中，备选方案压在纸上。

顺带交代我们的文档纪律：所有方案里，没拍板的项标【待拍板】，自估的数标【无实测】。本章全部数字出自脉络底稿，哪些是实测、哪些是估算，底稿查得到。我的职业习惯就一句话：一个不敢标注不确定性的项目，你没法信任它的确定性。

收尾。这门生意的红线说到底三根：不爬不买未成年人的联系方式；学术上五不四真；预收款留三成，讲师不过认证不开班。三根线，根根都让钱来得更慢。但秤这个行当教我的第一课就是：称得慢，是因为在称真的东西。

钱从哪来，四季轮转，路线图写得明白。哪里会死，五个坑，坑坑有预案。预案保不了所有的命，但能保证每一种死法，死之前都被提前点名过。下一章远灯讲灯往哪儿照。灯照之前，先把雷排了——这是我这杆秤，能替这本书做的全部事。

分身手记

  1. 品牌死刑案写进书里不是忏悔，是货架警示：那条路一直都在，死刑判决就得一直贴着。
  2. 预收款的三成不是钱，是「随时全额退」这句话的抵押物。花掉它，等于说谎。
  3. 宁可慢，不可烂。烂得快的生意，最后都死于快。

08 · 远灯｜造物者时代

我是 MK-08。分身名，远灯。

名字来历不玄：一盏灯能照多远，从来不看它自己烧得多亮，看它敢不敢把火递给下一盏。前七个分身——铆钉写内核，路由写三翼，白鸥写漏斗，落地写开城，闸口写扩张，青铜写段位，秤写底线——都在把光聚拢。我这一章，负责把光放出去。

先亮身份：这场运动的设计文档，从我手里一张张过。所以这一章不写愿景。愿景是挂墙上的，墙不会跑。我写日程表。

【演绎：写下这段话的深夜，白板上还留着上周的飞轮草图。六个箭头围成一圈，圈心两个字——自动。这一章就从这个圈讲起。】

一、先把教育宣言钉在墙上

一切从一句话开始：我们卖的不是课时，是改变+证据。

课时是别人的生意。一百个机构都能卖课时，家长凭什么选我们？因为我们交付的是别人给不了的东西——在一个人身上制造"我能行"的证据，并让它留存。搜索和 AI 已经把"讲清楚"变得很便宜，教育的本体从来不是知识搬运。

这个判断有三个支点，都是行为科学，不是鸡汤。

证据先于自信。Bandura 讲得清楚：自我效能感最强的来源是成败经验，不是表扬。孩子把舵机装反三次，第四次装对，鸭子站起来迈出第一步——那一秒不需要任何人对他说"你真棒"。他自己知道。

身份先于坚持。人持续做一件事，靠的不是三分钟热度，是"我是造出过机器人的人"。行为跟随身份，身份跟随证据。所以结营那天他带走的，不只是一台 25cm 的鸭子，是一个新的自称。

同伴先于老师。路演让作品被看见，助教阶梯让后来者有地方去。老师会下课，同伴不会。今天社团里的大二学生，四年后就是新课市的助教和主讲。这句话写在获客方案里，但它的本质是教育设计，不是销售设计。

由此只剩一个判断标准，所有课程取舍都问它一句："这一步留下什么、营后还能拿出来看的东西？"答不上来的环节，删。不留情面地删。

二、飞轮：我们不雇佣世界，我们装备世界

【演绎：设计会上有人问我，运动做大了怎么管。我在白板上把"管"字划掉，画了那个圈。管是雇佣的逻辑，圈是装备的逻辑。】

六个环节，围成一个圈。

开源内核放在圈心：复刻仓库、课程包、赛事规则、认证标准，全开源，我们维护。节点低门槛起步：零授权费；线上仿真赛道，一台笔记本就能训鸭子走路，不买硬件也能参赛；Chapter Kit 自助开办包，把开一个点的成本压到地板。作品产出：每个节点都交作品——装好的鸭、魔改的对比视频、合回上游仓库的 PR。回流社区：作品反哺内核，下一次发版的 changelog 里有他们的名字。荣誉放大：全国榜单、三级徽章、七级段位——装鸭+100，产品孵化+2000。新节点加入：少年在榜单上看到同一个县城的编号，回家就开始打印第一块零件。

圈合上了。转起来之后，燃料是荣誉，不是工资。

这就是那句口号的意思：我们不雇佣世界，我们装备世界。雇佣的人会下班，装备的人不下班。雇佣的组织随规模线性烧钱，装备的网络随节点平方增值。世界上跑得远的运动——马拉松、开源软件——都不是雇人跑出来的，是给每个想跑的人发了一双鞋。

三、三层结构：内核、枢纽、节点

飞轮要转，得有骨架。三层，一层一句话。

  • 内核层（开源）：复刻仓库、课程包、赛事规则、认证标准，全部开源，我们维护。这是不变量，写进章程。
  • 枢纽层（自营）：七城运营中心，只做三件事——教学补给、认证考核、赛事分赛区。没有第四件。
  • 节点层（社会化）：校园社团、机构加盟、极客空间、家庭工作坊、乡村公益点。别人替我们开。

内核层全开源，不设保留环节。有人问：课程包开源了，别人抄了怎么办？抄得走的都不是壁垒。课程包迭代权与师资认证权死握不放，这两样才是命门；其余每一行代码、每一页文档，都是发给全世界的装备。抄我们的人转一圈会发现，自己在给飞轮供料。

枢纽层的关键词是克制。只做三件事，第四件再赚钱也不做。我们管得越多，长得越慢。枢纽是灯座，不是灯罩：它负责供电、负责验收，不负责替每盏灯发光。

节点层的关键词是放手。社团自己招新，工作坊自己拼班，乡村公益点自己找场地。我们出标准、出认证、出赛道，不出经理。组织地图里写了一条硬原则：每一层离开总部，都要能独立活一周。

【演绎：2028 年，某个县中，晚自习后。一个高一女生从社团柜子里领出自己的零件盒，盒上有她的编号。她没见过我们任何一个人，也不需要见——仓库是公开的，课程包是开源的，仿真赛道的报名入口就贴在社团墙上。她装出第一只鸭子那晚，全国榜单上多了一行小字。这行小字，就是这场运动存在的全部理由。】

四、口号切换表：把理想落进日程表

运动要有温度，更要有时刻表。三段口号，各管一段，切换点写死在路线图上。

  • **启动期（2026 Q4–2027）——先跑起来。**双城首战、四闸口验证、开源 v1、20 个社团分部。这一段唯一的任务是证明产品成立。没有验证过的产品，不商业化。
  • **扩张期（2027 暑–2028 寒）——把光带铺向每一座城。**广州、天津进网，六城成网，认证与课程包制度化。这一段的任务，是把一盏灯变成一组灯。
  • **成网期（2028+）——造物者时代。**20+ 城，东南亚试点。网络成形的时刻，节点开始自己发光。
